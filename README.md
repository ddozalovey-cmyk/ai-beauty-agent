# 💄 AI 맞춤 뷰티 에이전트 PRO (AI Personal Beauty Agent)

OpenCV 기반 정밀 얼굴 계측(3분할 황금비, 눈매 각도)과 YouTube 공식 API를 결합한 맞춤형 메이크업 추천 AI 웹 애플리케이션입니다.

## 🌐 Live Web App (바로가기)
👉(https://my-custom-makeup.streamlit.app/)

---

## 🎯 주요 활용 목적 (Use Cases)
- **내 얼굴형에 어울리는 메이크업 찾기:** 계란형, 둥근형, 긴 얼굴형에 따른 맞춤 컨투어링 & 섀딩법 매칭
- **이목구비 비율(3분할) 맞춤 교정:** 상안부, 중안부(긴 코/짧은 코), 하안부 비율 분석을 통한 맞춤 애교살·오버립 테크닉 제안
- **눈매 맞춤 아이메이크업 추천:** 올라간 눈매(밑트임), 처진 눈매(캣츠아이), 수평/무쌍 눈매(가로 확장 음영) 튜토리얼 자동 추천
- **원하는 연예인 스타일 결합:** 장원영, 아이유, 고현정 등 원하는 연예인의 화장 스타일과 내 얼굴 특징을 결합한 최적 솔루션 도출
- **100% 안심 개인정보 보호:** 사진은 서버에 저장되지 않고 휘발성 메모리(RAM)에서 분석 후 즉시 영구 삭제

---

## 🛠️ 핵심 기능 (Features)
1. **정밀 얼굴 계측 (Vision Engine):** OpenCV 기반 황금 3분할 비율 및 눈매 각도 정밀 판별
2. **전문가 테크닉 매핑 (MUA Mapping Matrix):** 단순 키워드 검색이 아닌 전문 메이크업 아티스트 화장 기법(윤곽 섀딩, 음영 테크닉 등)으로 자동 변환
3. **유튜브 공식 큐레이션 (YouTube Data API v3):** 검증된 최적의 메이크업 영상을 임베드 형태로 안전하게 제공
4. **다국어 지원 (Multilingual):** 한국어 및 영어(English) 원클릭 UI & 검색어 자동 전환 지원
