# 💄 AI 맞춤 뷰티 에이전트 PRO (AI Personal Beauty Agent)

OpenCV 기반 정밀 얼굴 계측(3분할 황금비, 눈매 각도)과 YouTube 공식 API를 결합한 맞춤형 메이크업 추천 AI 웹 애플리케이션입니다.

## 🌐 Live Web App (바로가기)
👉 **[AI 뷰티 에이전트 웹 서비스 실행하기](https://여기에-본인의-streamlit-주소-입력.streamlit.app)**

---

## ✨ Key Features (주요 기능)
- **Face Ratio Analysis**: 얼굴 3분할(상·중·하안부) 및 눈매 가로/세로 비율 정밀 계측
- **Technique-based Querying**: 단순 키워드가 아닌 윤곽/음영 전문 메이크업 테크닉 자동 변환 매칭
- **Privacy-First Engine**: 업로드된 이미지는 서버에 저장되지 않고 휘발성 RAM 처리 후 즉시 파기
- **Community Reranking**: SQLite 기반 피드백 루프 탑재로 사용자 반응 실시간 반영
