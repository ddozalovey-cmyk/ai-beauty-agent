## 🛡️ 100% 안심 개인정보 보호 아키텍처 (Privacy & Security)
대부분의 얼굴 분석 앱이 사용자 사진을 서버에 수집·저장하는 것과 달리, 본 앱은 철저한 프라이버시 보호 구조로 설계되었습니다:

1. **서버 비저장 (No Server Storage):** 클라우드 서버 스토리지나 데이터베이스에 사진 파일을 절대 업로드/저장하지 않습니다.
2. **휘발성 RAM 임시 연산:** 사진을 올리는 순간 브라우저 세션의 휘발성 메모리(RAM)에서 얼굴 3분할 및 각도 수치만 순간 계산합니다.
3. **즉시 영구 소멸 & 수동 삭제 지원:** 분석이 완료되면 즉시 메모리에서 소멸되며, 사용자가 사이드바의 **[🗑️ 사진 메모리 즉시 영구 삭제]** 버튼을 눌러 메모리를 직접 즉각 비울 수도 있습니다.

## 💄 내 얼굴 맞춤 솔루션 주요 기능 (Core Features)
사진 한 장으로 내 이목구비의 장단점을 과학적으로 분석해 최적의 뷰티 유튜브 영상을 매칭합니다.

- **얼굴 3분할 황금비율 계측:** 상안부, 중안부(긴 중안부 축소 섀딩/오버립), 하안부 비율 정밀 진단
- **눈매 맞춤 아이메이크업:** 올라간 눈(밑트임/강아지상), 처진 눈(캣츠아이 리프팅), 수평/무쌍(가로 확장) 테크닉 자동 추천
- **연예인 스타일 결합:** 장원영, 아이유, 고현정 등 원하는 연예인의 화장법과 내 얼굴형의 최적 조합 도출
- **공식 유튜브 큐레이션:** 구글 공식 YouTube Data API v3를 통해 저작권 걱정 없는 정식 임베드 튜토리얼 제공
- **글로벌 다국어 지원:** 한국어(Korean) 및 영어(English) 원클릭 UI & 검색어 자동 변환
